# Mirror Archives: latches and locking recesses
Levels 21–22 use existing collision geometry. A latch records effective held state in the immutable room, even after the physical contact ends. A locking shape socket captures a matching key on commit; it is no longer selectable. Undo restores the preceding room snapshot; reset restores the authored room. Preview is pure and warns about capture.
Level 21: translate the weight (6,0) to latch the first gate, then (8,0) to hold the second.
Level 22: translate the weight (6,0) and the key (14,0) to the exit recess. The spare alcove recess captures the same key, making the exit unreachable until undo/reset.
Both target two casts and three stars. The intended routes use the lower corridor; mechanism shelf is above the player's walking path. Human playtesting remains pending.
