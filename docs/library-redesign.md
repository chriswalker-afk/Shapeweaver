# PR41 — Adventure library redesign

The previous screen repeated chapter availability, transformation names, two difficulty numbers and completion text for all 36 puzzles, with an awkward seventh chapter tile. The new interaction is deliberately two-stage: a chapter atlas (seven original landscapes, compact progress bars, no puzzle wall), then a chapter-specific selection screen (four or six numbered tiles with spell icons and stars). A selected tile updates one inspector showing the title, formal spell names, both five-point difficulty ratings and personal best. Play is explicit; selection alone never starts a level. Optional Find a puzzle retains all four existing cross-campaign filters; search results also show short titles. The header retains Continue and progress, and all 36 puzzles remain available without locks. Back to Chapters restores focus to the chosen chapter. Returning from a puzzle selects its chapter and tile; entering from home resets to the atlas. The library's existing Continue still chooses the next unfinished puzzle (or replays after completion); home Continue retains paused-attempt behaviour.

Art: seven locally authored 320 × 160 storybook SVG scenes with consistent perspective/lighting and distinctive motifs/palettes. Wide screens use a balanced 4+3 chapter grid; intermediate 3+3+1 and portrait 2+2+2+1 centre the last row. Short landscape prioritises smaller cards and a side-by-side puzzle inspector. Portrait stacks the picker and inspector and allows normal page scroll. No gameplay, score, progression, storage or home changes. Accessibility: native buttons, accessible names include title and score, aria-pressed selection with arrow-key navigation and a single selected tab stop, named spell labels, numeric difficulty as well as pips, visible focus, no focus outline on programmatically focused headings. No new third-party dependencies.

QA: preserve all existing filter assertions, 36-level campaign audit, 144 level/viewport browser checks and workshop QA. Add focused library screenshot/report artifact and verify art decoding/provenance, chapter balance, progressive disclosure, keyboard/touch, filter combinations/no results, exact puzzle selection, return selection, progress, narrow/zoom reflow. Human screenshot review and actual classroom device acceptance remain required.
