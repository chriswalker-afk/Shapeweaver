# PR07 — Translation and Across the Brook

## Tutorial
From the title choose Level 1 · Across the Brook. The practice room remains a separate preview-only room. Open Objects, choose the timber beam and Translation, enter a signed column vector (horizontal component above vertical), Preview and Apply. The original and image vertices are labelled; the preview reports errors without moving anything. The level is 40 × 12 units; west bank ends at x=16, east bank begins at x=26. A 12-unit beam starts with A=(3,3). One good destination is (15,3), giving vector (12,0). The beam sits half a unit above the bank surface, so jump onto it and walk across to the portal. The three optional hints progress from obstacle to coordinate comparison to a worked vector, using the current beam position. This first tutorial deliberately uses a zero vertical component so the straight-line path does not cut into support terrain. Future levels will use both components. No hard-coded target coordinate in exit detection; alternate legal bridges and corrective moves are accepted.

## Full-path validation
PR06's final-pose check is necessary but insufficient. PR07 decomposes simple polygons into convex triangles and uses continuous separating axes: for each pair, intersect time intervals of positive overlap along every normal for t in [0,1]. This rejects intermediate collisions, including thin obstacles that point sampling would miss. Boundary contact alone is allowed. Check terrain, other solid props, hazards and apprentice; convex world bounds are checked at endpoints. A supported object must have contact beneath at the final pose; no load-bearing analysis or support chain for dependent objects yet. Moving a player's supporting object is rejected. A clear ghost means both path and final pose clear for translation only; other previews are unchanged.

Apply recomputes from current room and player. On success return a new frozen room and matching physics index, then swap both in the controller. No partial mutation. Count successful commits, including valid but unhelpful moves. Rejected previews and failed commits do not count. The visual beam interpolates from old to new pose over 0.65 s; simulation and competing spell/pick input are paused until it finishes. Reduced-motion skips the animation. The actual world state is already committed, so animation timing cannot alter the geometry. Reset restores initial geometry, player, moves and hints. Opening a room from the title starts a fresh attempt. Falling returns to spawn without rolling back the beam. No stars, undo or persistent progress until PR11–15.

## Tests
Continuous sweep tests cover thin walls, diagonal vectors, legal sliding contact, concave voids, player/hazard intersections and start/end-only checks. Transaction tests verify immutable source, new collision geometry, unchanged rejected state, repeated casts and actual traversal with recorded input steps. The intended solution is an achievable one-move route, not a proof of optimality across every possible movement sequence. Browser playtesting and visual/touch sign-off remain necessary. PR08 adds actual rotation and Level 2, using the same preview/commit boundary.

Recorded traversal at 120 Hz: apply (12,0) at spawn, hold right for 215 ticks, hold right and press jump on the first of 120 ticks, then hold right for 400 ticks (simulation freezes at actual exit). At the jump landing the feet are on the translated beam at y≈3.5. The replay completes with zero respawns. Equivalent placements and corrective casts are tested separately.
