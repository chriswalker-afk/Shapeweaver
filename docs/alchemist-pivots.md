Level 27: The Wandering Pivot. Select the brass socket and translate by (14,0). The beam is carried by the socket, with shared H moving from (8,4) to (22,4). Select the beam; rotate 90 degrees clockwise about the current H, then jump onto the deck and cross.

## Dependency contract
A carrier is a separately selectable solid polygon permitting translation or reflection; one attached enchanted beam permits rotation about the shared hinge. Both are transformed by the same mathematical map for carrier casts, with destination and continuous translation path validated for both. Rotation of the beam treats the socket as a solid stationary object. Preview shows both images and the new pivot; animation and immutable undo update both atomically. Authoring supports copying campaign rooms and moving a carrier together with its child. No general nested attachments, independent detachment, resizing a carrier, or new palette template in this PR; strict validation rejects inconsistent links.
The two intended solutions cost two casts. Geometry, not an imposed cast sequence, determines legality. Other valid routes are allowed. Campaign audit checks distances/area for carried parts as well as the selected object; workshop replay and browser tests cover both levels. Manual visual/classroom review remains pending.
