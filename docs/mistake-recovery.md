# PR11 — Mistake recovery

Three different actions, always distinguishable:
- **Undo** rolls back the most recent still-active successful cast. Each cast retains an immutable previous room, including vertices, IDs and future plain-data mechanism properties, and a pre-cast player snapshot. If the player was safely grounded, restore that point; otherwise use a remembered, validated last grounded point from that world, then the already-visited checkpoint or spawn. Rebuild collision geometry and check the recovery point before swapping state. Restore facing/checkpoint from the snapshot where valid; clear motion, climbing, buffered input, preview, selection, marker and stale hints. Return the camera to follow mode. No inverse spell is calculated or cast. Multiple undos work in reverse order. Undo does not consume a new move and does not refund the original successful move. Undone casts remain in ordered attempt history. No redo yet. Undo is unavailable during cast animation or after level completion.
- **Return to safety** uses the same safe destination rule as automatic hazard recovery: last visited valid checkpoint, otherwise valid spawn. Preserve the transformed world and all moves, clear competing interaction, reset player velocity and input. Count a return/respawn for diagnostics only, not as a transformation. Manual return failure leaves the current player/world unchanged and suggests Undo or Reset.
- **Reset** restores the original room/player, clears animation, active cast stack, recorded moves, undo markers, hints and return count. It is a fresh attempt even during animation. Grid/axes and camera zoom preferences remain. Switching levels also clears attempt state.

Safety: destinations must be finite, dry, clear and supported in the exact restored/current physics world. Never use an unvisited checkpoint. If a fall has no valid checkpoint or spawn, the player freezes in a recovery-required state; Undo restores prior safe geometry if possible, otherwise Reset. No general puzzle-solvability detector, arbitrary teleport to unvisited areas or automatic rejection of every inefficient/stranding cast. The safe snapshot applies to the current plain-data room model; future persistent mechanism state must be included in room snapshots. A cast while airborne uses the last validated grounded location instead of recreating an unsafe fall. Recovery cannot refund the efficiency cost of experimenting.

Invalid previews and rejected commits leave the world, player and move history unchanged. Keep precise reason codes; show a red ghost where calculable, specific next action (e.g. move off the object, inspect the entire arc, choose a supported destination, correct the input format), and "No move used." Valid but unhelpful casts are accepted. Clear preview is free. No countdown or time penalty.

Attempt summary exposes total committed moves, undone count, active move count, returns and ordered records with undone flags; the existing raw records accessor still returns all committed records. PR12 can use this for stars and mathematical history. No rating, persistent progress or redo in PR11. Completion locks undo and return until reset. Tests cover all four spells, rollback geometry/IDs, player safety, multiple undos, failed return and blocked respawn recovery, move accounting, stale UI and reset during animation. Actual browser visual/touch review remains outstanding.
